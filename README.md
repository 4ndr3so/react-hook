 ⚛️ React + Redux Practice

This repository contains practice exercises and mini-projects using **React** and **Redux Toolkit**. It is intended to strengthen understanding of state management, component structure, and common patterns used in modern front-end development.

---

## 🧠 Skills Practiced

- Functional components and hooks
- Centralized state with Redux Toolkit
- Actions, reducers, and slices
- Asynchronous logic with `createAsyncThunk`
- Component-level and global state separation
- Integration with APIs and side effects
- DevTools and debugging best practices
